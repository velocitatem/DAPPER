Detailed Description

PyTorch Dataset for loading images and extracting text via OCR from MinIO.

This class extends PyTorch's Dataset class to load images from MinIO object storage and utilize pre-computed OCR results from the dataframe.

PyTorch Dataset for loading images and pre-computed OCR text from MinIO.
