Detailed Description

Large-Small (LS) Convolution module for LSNet.

This module implements the core LS convolution operation that combines large-kernel perception and small-kernel aggregation for efficient feature extraction. Based on the "See Large, Focus Small" strategy from the LSNet paper.

Large-Small (LS) Convolution module as described in the LSNet paper.

This module combines large-kernel perception and small-kernel aggregation
to efficiently capture a wide range of perceptual information and achieve
precise feature aggregation.
