Detailed Description

HuggingFace Invoices dataset loader for document classification.

This module provides functionality for loading and processing invoice images from the HuggingFace datasets repository. It handles data loading, image conversion, augmentation, and integration with MinIO storage for document classification tasks. source: https://huggingface.co/datasets/katanaml-org/invoices-donut-data-v1
